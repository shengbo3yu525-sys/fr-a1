# 法语 A1 词汇复习

纯前端、可离线、手机浏览器打开即用的法语 A1 词汇复习工具。
主动回忆 + Leitner 五盒间隔重复 + 多方向考察，每张卡片独立记熟练度。

词库来自 `积累.xlsx` 的 **github** 表：**904 个词条**（1038 行原始数据，阴性形式已合并进阳性词条），共 **3291 张卡片**。

---

## 一、文件结构

```
index.html        界面 + 样式（改外观改这里）
app.js            全部逻辑：调度、判分、统计、导入导出

```

## 二、部署到 GitHub Pages

1. 在 GitHub 新建一个仓库，例如 `fr-a1`。
2. 把这个文件夹里的所有文件（`index.html`、`app.js`、`data/`、`icons/`、`manifest.json`、`sw.js`）传上去，放在仓库根目录。
   - 网页上传：仓库页 → **Add file → Upload files** → 把文件夹整个拖进去 → Commit。
   - 命令行：
     ```bash
     git init && git add . && git commit -m "init"
     git branch -M main
     git remote add origin https://github.com/你的用户名/fr-a1.git
     git push -u origin main
     ```
3. 仓库 → **Settings → Pages** → Source 选 **Deploy from a branch** → 分支 `main`、目录 `/ (root)` → Save。
4. 等 1–2 分钟，网址是 `https://你的用户名.github.io/fr-a1/`。

> 注意：所有路径都是相对路径（`./app.js`），放在子目录也能正常工作，不用改代码。

**Vercel**：直接 `vercel --prod`，或在网页端 Import 这个仓库，框架选 Other，其余留空。

### 添加到手机主屏幕

- **iPhone（Safari）**：打开网址 → 分享按钮 → 「添加到主屏幕」。之后从主屏图标进入，全屏、无地址栏、断网可用。
- **安卓（Chrome）**：右上角菜单 → 「安装应用」/「添加到主屏幕」。

### 更新了代码怎么办

Service Worker 会缓存旧版本。改完代码后，把 `sw.js` 里的 `const CACHE = 'fr-a1-v1'` 改成 `'fr-a1-v2'`（每次改都 +1），推上去，手机上刷新一到两次即可拿到新版本。

## 三、备份与恢复学习记录（重要）

进度存在浏览器的 `localStorage` 里。**iOS Safari 在长期不用时会清理站点数据**，所以务必定期备份。

- **导出**：更多 → 数据备份 → 「⬇️ 导出进度 JSON」，文件名形如 `法语A1进度-2026-08-11.json`。存到微信收藏 / 网盘 / 邮箱都行。
- **恢复**：更多 → 「⬆️ 导入进度 JSON」→ 选那个文件。会整体覆盖当前进度。
- 建议：每周导出一次，或每次学完一个单元导出一次。
- 把网页「添加到主屏幕」后，数据被清理的概率会明显下降。

## 四、替换 / 扩充词库

### 方法 A：在应用里直接导入（最简单，不用碰代码）

更多 → 数据备份 → 「⬆️ 导入词库 CSV/JSON」。

CSV 表头支持中英文别名（顺序随意，缺的列留空即可）：

| 列名（任选其一） | 说明 |
|---|---|
| `单词` / `fr` / `word` | 法语词，**可以带冠词**，如 `le café`，会自动拆出冠词和阴阳性 |
| `中译` / `zh` / `中文` | 中文释义，多个意思用 `;` 分隔 |
| `词性` / `pos` | 如 `n.m.` `n.f.` `v.t.` `adj.` |
| `音标` / `ipa` | 可选 |
| `标签` / `单元` / `tags` | 主题标签，用于筛选，如 `U1` |
| `阴性` / `fem` | 形容词/名词的阴性形式，有就会生成「阴性变形」卡 |
| `备注` / `note` | 发音规则等，答错时会显示 |

示例：

```csv
单词,中译,词性,音标,标签,阴性
le chat,猫,n.m.,/lə ʃa/,动物,
la souris,老鼠,n.f.,/la su.ʁi/,动物,
heureux,幸福的,adj.,/ø.ʁø/,情绪,heureuse
```

导入时会**按法语单词自动迁移学习进度**：新旧词库里都有的词，熟练度保留；新词库里没有的词，其进度会丢弃。导入前先导出一份进度备份更保险。

> 想恢复内置词库：更多页导入一个空白？不行——最简单是清浏览器数据前先导出进度，或直接用无痕窗口试。日常建议只做「扩充」而不是「替换」。

### 方法 B：直接改 `data/words.js`（推荐用于长期维护）

文件内容是一行 `window.WORD_BANK = [ ... ];`，每个词条的字段：

```js
{
  id: "w0005",          // 唯一，学习记录靠它对应，不要随意改已有词的 id
  fr: "café",           // 法语原形，不含冠词
  article: "le",        // 冠词（le/la/l'/les），没有就留 ""
  pos: "n.m.",          // 词性原文
  posBase: "n.",        // 粗分类：n. / v. / adj. / adv. …
  gender: "m",          // "m" / "f" / null
  plural: false,
  zh: "咖啡",            // 中文释义，多义用 ; 分隔
  ipa: "/ka.fe/",
  note: "…",            // 发音提示，答错时显示
  tags: ["U1"],         // 主题/单元标签
  level: 3,
  genderCard: true,     // 是否出 le/la 卡（单数普通名词才为 true）
  fem: "chinoise",      // 可选：阴性形式，有则生成阴性变形卡
  femIpa: "/ʃi.nwaz/"   // 可选
}
```

### 方法 C：改 Excel 后重新生成

改完 `积累.xlsx` 的 github 表，然后：

```bash
pip install openpyxl
python3 build_words.py          # 脚本里 SRC 改成你的 xlsx 路径
```

会重新生成 `data/words.js`。脚本做的事：跳过表头和词性对照区、按 `A1 U1…U8` 打标签、把没有独立中文释义的阴性形式合并进阳性词条、从冠词和词性推断阴阳性、合并重复词条并合并释义。

## 五、功能说明

### 五类卡片，各自独立计分

| 卡片 | 考什么 | 怎么答 |
|---|---|---|
| 法 → 中 | 识别 | 显示答案后自评「想起来了 / 没想起来」 |
| 中 → 法 | 产出 + 拼写 | 打字，自动判分 |
| 发音 | 发音 | 先自己读 → 播放标准音 → 自评「一致 / 有出入 / 完全不会」 |
| 阴阳性 | le 还是 la | 两个大按钮（496 个名词有这张卡） |
| 阴性变形 | 阳性 → 阴性 | 打字（83 个词有这张卡） |

### Leitner 五盒

| 盒子 | 下次复习 |
|---|---|
| 1 | 1 天 |
| 2 | 3 天 |
| 3 | 7 天 |
| 4 | 15 天 |
| 5 | 30 天 |

- 答对：盒子 +1（上限 5），重算日期
- 答错：直接掉回盒 1，并在**本次会话里稍后再出现一次**（最多补考 2 次，避免死循环）
- 发音卡「有出入」：盒子原地不动
- 补考不重复计分，一张卡每次会话只计一次正确/错误
- 错误次数只用于统计和顽固词判定，不直接影响调度

### 会话

- 默认每次 20 张（可调 10/20/30/50），做完即停
- 优先今日到期的复习卡（按逾期天数降序），剩余名额补新词
- 每日新词上限默认 10 **个词**（不是 10 张卡），可调 0/5/10/20/30
- 完成页显示：正确率、用时、新学词数、明日待复习数、本次错的词
- 首页可按单元 U1–U8 筛选，只练某几个单元

### 中文一对多的处理

- 中文释义带限定信息（照搬 Excel 原文，如「边;侧面」）
- 卡片上显示词性和阴阳性提示，可点「首字母提示」
- 同一个中文对应多个法语词时（词库里有 101 组，如「天」= jour / journée），**写出其中任意一个都判对**，答案页会列出其它同义词

### 判分宽容度

- 忽略大小写、首尾空格、多余标点
- 忽略冠词：写 `le café` 或 `café` 都对
- **重音符号写错默认判对**，但正确写法会用红色波浪线标出；设置里可开「严格模式」改成判错
- 判错后还有「其实我答对了，算对」按钮兜底

### 顽固词

- 连续答错 5 次自动标记，并**移出常规队列**（不再加大频率）
- 「更多」页单独列出，可以给它写联想/例句（会保存）
- 点「已处理」后重置回盒 1 放回队列

### 统计

- 总览、盒子分布柱状图（可切换卡片类型）、未来 14 天复习量、学习热力图（近半年）
- 词表：按错误次数降序排（默认），一眼看到最薄弱的词；也可按字母、熟练度、复习日期、未学优先排序
- 点任一词打开详情：每类卡片的盒子/对错/连错/下次复习，可重置进度或标记已掌握

## 六、关于发音

用系统自带的 `SpeechSynthesis`（`lang = fr-FR`），必须由点击触发（iOS 限制）。

如果没声音，多半是系统缺法语语音包：

- **iPhone**：设置 → 辅助功能 → 朗读内容 → 声音 → 法语 → 下载
- **安卓**：设置 → 系统 → 语言与输入法 → 文字转语音输出 → 安装语音数据 → 法语

没装的时候应用会弹提示。发音语速可在设置里调（慢/中/正常）。

**没有做语音识别**：Web Speech API 的 `SpeechRecognition` 在 iOS Safari 上基本不可用，而且对二语学习者的口音误判率很高，正确但带口音的发音常被判错，反而打击信心。所以发音卡用自评式。
